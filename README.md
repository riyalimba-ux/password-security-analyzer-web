## 🚀 About the Project

SecurePass Pro is a **modern password security analyzer** that provides:

- 🔴 Real-time password strength analysis  
- 📊 Entropy calculation  
- ⏱️ Crack time estimation  
- 💡 Smart suggestions  
- 🎨 Interactive modern UI  

---

## 🎯 Live Features

✨ Type your password → get instant results  

✔ Strength meter  
✔ Entropy (complexity)  
✔ Crack time estimation  
✔ Suggestions to improve security
